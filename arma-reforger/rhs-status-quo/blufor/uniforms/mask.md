# Mask

Simple tactical mask designed to conceal the face while providing basic protection against weather and environmental conditions.

## Specifications

| Category | Data |
| --- | --- |
| Name in game | Balaclava |
| Weight | 170 g |
| Faction | Russian forces (REDFOR) |

## Variants

The item is available in these versions:

* Balaclava
* Balaclava - ATACS-FG
* Balaclava - Black
* Balaclava - Coyote
* Balaclava - MCAM
* Balaclava - Olive Drab
* Balaclava - Tan
