# T-90M

{% hint style="info" %}
First listed in the **0.15** changelog.
{% endhint %}

The T-90M 'Proryv-3' is a modernized Russian main battle tank armed with a 125mm 2A46M-5 smoothbore gun. It features the Relikt explosive reactive armor package, additional NERA armor kits, a new welded turret, an upgraded Kalina fire control system, and the Shtora-1 electro-optical protection system, serving alongside the T-14 'Armata' in Russian armored units.
