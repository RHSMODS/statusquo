# Mi-8MT

{% hint style="info" %}
First listed in the **0.6** changelog.
{% endhint %}

The Mi-8MT is a Soviet and Russian medium transport helicopter. RHS adds gray versions of the transport and the armed transport helicopter, based on the Arma Reforger Mi-8MT.

## Specifications

| Category | Data |
| --- | --- |
| Name in game | Mi-8MT Transport Helicopter (Gray) |

## Variants

The item is available in these versions:

* Mi-8MT Transport Helicopter (Gray)
* Mi-8MT Armed Transport Helicopter (Gray)
