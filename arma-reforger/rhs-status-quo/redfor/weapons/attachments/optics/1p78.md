# 1P78

{% hint style="info" %}
Introduced in **0.2.414**
{% endhint %}

2.8× magnified optic. The 1P78 'Kashtan' is a telescopic sight in use with the Russian Armed Forces, intended as a replacement for the older PSO-1 and 1P29 scopes. Dovetail mounted.
