# 1PN93

{% hint style="info" %}
Introduced in **0.2.414**
{% endhint %}

4× magnified night vision optic. The 1PN93-1 (AS) is intended for observation and engagement with the AS, VSS, and SR-3 rifles under natural night illumination. Dovetail mounted.

## Specifications

| Category | Data |
| --- | --- |
| Name in game | 1PN93-1 (AS) Scope |
| Weight | 580 g |

## Variants

The item is available in these versions:

* 1PN93-1 (AS) Scope
* 1PN93-2 (RPG) Scope
* 1PN93-3 (PKM) Scope
* 1PN93-3 (SVD) Scope
* 1PN93-1 (AK) Scope
