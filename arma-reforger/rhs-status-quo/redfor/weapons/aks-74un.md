# AKS-74UN

{% hint style="info" %}
Introduced in 0.2.693
{% endhint %}

5.45×39mm compact carbine. The AKS-74U was developed for use with special forces, airborne infantry, rear-echelon support units, and vehicle crews where a full-length rifle was impractical. The 'N' variant features a dovetail optics mount.

## Specifications

| Category | Data |
| --- | --- |
| Name in game | AKS-74UN |
| Weight | 3.07 kg |
| Default magazine | 30Rnd 6L23 Plum Mag (7N10) |
| Rate of fire | 750 rounds/min |
