# AN-94

{% hint style="info" %}
Introduced in **0.2.414**
{% endhint %}

5.45×39mm assault rifle. Originally developed as a potential replacement for the AK-74, the AN-94 is known for its unique two-round burst mechanism designed to enhance accuracy and reduce recoil during sustained fire.

## Specifications

| Category | Data |
| --- | --- |
| Name in game | AN-94 |
| Weight | 3.85 kg |
| Default magazine | 30Rnd 6L23 Plum Mag (7N10) |
| Rate of fire | 650 rounds/min |

## Variants

The item is available in these versions:

* AN-94
* AN-94 (Picatinny)
