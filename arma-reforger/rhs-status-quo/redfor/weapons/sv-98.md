# SV-98

<!-- TODO: confirm the version that introduced the SV-98 and add the "Introduced in" hint -->

7.62×54mmR bolt-action sniper rifle. The SV-98 was developed at Izhmash from the Record target rifle and adopted in 2003 as part of the 6S11 sniper system.

<!-- TODO: screenshot of the SV-98, three-quarter view (sv-98-side.webp) -->

## Description

The SV-98 feeds from a 10-round detachable box magazine. It has a flash hider on the muzzle and an adjustable iron sight.

The rear sight has a slider. Each sight setting moves the slider to a different height. The top of the front post aligns with the top of the rear sight leaf at all settings.

## Usage

Use the sight settings to set the range to the target:

1. Aim down the sights.
2. Change the sight setting to the range to the target. The rear sight slider moves.
3. Put the top of the front post level with the top of the rear sight leaf.
4. Put the target on the top of the front post.
5. Fire.

{% hint style="info" %}
The SV-98 is a manual (bolt-action) weapon. The character operates the bolt after each shot.
{% endhint %}
